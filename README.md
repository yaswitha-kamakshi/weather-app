# Weather App

A simple weather web application built with Python and Flask.

**Live demo:** https://weather-app-l750.onrender.com

## Features
- Search weather by city name
- °C / °F toggle
- Next 24 hours forecast with rain chance
- 3-day forecast
- "Use my location" button
- Remembers your last searched city
- Weather icons and background themes that change with conditions

## Tech Stack
- Python, Flask
- Open-Meteo API (free, no API key needed)
- HTML, CSS, JavaScript
- Deployed on Render

## Run locally
1. Install the requirements:
   pip install -r requirements.txt
2. Start the app:
   python -m flask --app app run
3. Open http://127.0.0.1:5000 in your browser
